# 第一轮人工复核（作废，仅存档）

这一轮的 40 段回放视频是用有 bug 的回放渲染生成的。当时的渲染器通过 gym_pusht 的 `reset_to_state` 设置每一步的状态，而它内部的 `_set_state` 会先设置物块位置、再设置角度。设置角度时，T 会绕重心旋转，位置也随之偏移，所以视频里 T 的位置和朝向都不对。

自动分类不受影响，因为它直接使用记录下来的真实状态。但人工看到的画面是错的，所以这一轮的一致率不能用来评价分类规则。修复见提交 “Fix replay rendering of the T pose”，并新增了回归测试 `tests/test_replay.py`。

| 指标 | 数值 |
| --- | --- |
| 已标注 | 40/40 |
| 一致率 | 57.5% |
| Cohen's κ | 0.47 |
| 环境判定为成功的 8 个回合 | 人工只认出 1 个 |
| 物块从未被推动的 8 个回合（画面里 T 始终静止，不受渲染 bug 影响） | 人工全部认出（8/8） |

这一规律和渲染 bug 的预期一致：T 移动过的回合，画面才会画错。

第二轮复核重新抽样，并排除了这一轮出现过的回合（`make_review_sample.py --exclude`），视频用修复后的渲染器生成，结果在 `results/review/`。
