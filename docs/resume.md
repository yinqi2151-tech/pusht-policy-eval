# 简历表述（草稿）

## 完整版（评测 / 数据岗）

**具身策略鲁棒性评测｜LeRobot、Diffusion Policy、PushT、Python**　[GitHub 链接]

- **流程校验**：项目早期评测第三方权重时成功率只有 0–5%。核对训练配置后，发现其中的 Diffusion 权重只训练了 1000 步（官方为 20 万步）。修复 LeRobot 0.6.1 迁移旧格式权重时的配置序列化 bug 后，用官方权重复测：50 回合平均最高奖励 0.952（官方 0.955），成功率 54%（95% 区间 40–67%，包含官方的 65.4%）。确认评测流程可信、早期低分来自所选权重。
- **可重复性**：发现原生 LeRobot 评测在同一种子下两次结果分别为 0.614 和 0.392，定位到 cuDNN benchmark，用确定性设置修复；批量并行评测在可重复的前提下提速 【待填】 倍。用独立种子复测，推翻了早期一项 ACT 消融的乐观结论（+0.164 → +0.017）。
- **鲁棒性扫描**：在不修改 LeRobot 源码的前提下，为每个仿真子环境加入扰动层和逐步状态记录层，设计 4 类扰动 × 4 档强度、每个条件 100 个配对初始状态的实验，统计方法用精确 McNemar 检验加 Holm 校正。主要发现：【待填，例如“执行延迟达到 X ms 时成功率从 Y% 降到 Z%”】。
- **失败归因**：用逐步轨迹把每个回合自动分为 5 类结局（阈值在实验前固定），并对 【待填】 个回合做分层盲审，自动分类与人工判断的一致率为 【待填】（Cohen's κ = 【待填】）。

## 精简版（产品 / 运营岗）

- 为开源机器人策略搭建可复现的评测流程，先用官方基准校验评测本身（复现 0.952 / 0.955），再定位出早期低分的原因是所选模型训练不足。
- 设计配对的鲁棒性实验，用统计检验区分真实影响和随机波动，并把失败自动归为 5 类，再通过人工抽检验证分类的可靠性。

## 面试时说明

- 只评测了一个策略、一个仿真任务，扰动是合成的，结论不外推到真实机器人。

- 自动分类描述的是状态变化，不是失败原因；人工复核只覆盖抽样的回合。
